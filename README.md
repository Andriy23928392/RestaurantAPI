# 🍽️ RestoHub — Full-Stack Restaurant Management System

Сучасна система для управління рестораном, яка об'єднує клієнтський інтерфейс для замовлень та захищену панель шеф-кухаря. 

## 🛠 Технологічний стек
* **Backend:** ASP.NET Core 8.0 (C#)
* **Database:** SQLite + Entity Framework Core
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS, SPA)
* **Security:** JWT (JSON Web Tokens) для авторизації адмінки
* **Integrations:** Telegram Bot API (миттєві сповіщення про замовлення)

## 🚀 Головні функції
1. **Клієнтський SPA-інтерфейс:** Плавна навігація, корзина, розрахунок вартості на льоту.
2. **Система промокодів:** Працююча логіка знижок (напр. `KP5X`,).
3. **Панель Шеф-Кухаря:** Захищений вхід, статистика замовлень, генерація звітів у Excel.
4. **Управління меню:** Миттєве перемикання страв у "стоп-лист", завантаження реальних фото на сервер.
5. **Telegram-сповіщення:** Бот миттєво надсилає деталі нового замовлення персоналу.

Нижче наведена схема того, як працює ядро системи під час оформлення замовлення:

```mermaid

    API-->>UI: Відповідь 200 OK
